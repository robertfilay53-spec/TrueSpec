## Fix list

### F1 — Sentinel / overflow numbers (P1)

- GPU page: "Current mode: 1920 x 1080 x 4294967296 colors" (2^32).
  The Display page correctly shows "32-bit" for the same
  CurrentBitsPerPixel=32 value. Use bit depth, never 2^32.
- Network page: "Ethernet link speed: 9223372036854.8 Mbps"
  (Int64.MaxValue sentinel / 1e6). Show "Not reported by hardware"
  when the raw value is the unknown sentinel.
- Audit EVERY numeric display for sentinel/overflow values (MaxValue,
  -1, 2^32, 0 where 0 means "no reading"). Add regression tests that
  feed the sentinel values and assert "Not reported by hardware".

### F2 — Collector timeouts, structural (P1)

- System, Security and Drivers collectors each timed out after 10s.
  Windows Update, Startup and Crash history never ran ("Scan timed out
  before this collector ran"). One slow collector must not starve the
  rest.
- Fix: per-collector independent budgets and/or parallel collection
  with a global cap that still lets every collector report. Every
  collector must end in a result or a clear "not available", never a
  cascade of timeouts.
- Investigate WHY these three are slow on this machine (WMI query
  cost?) and make the queries fast. Do not just raise the timeout and
  hope.

### F3 — Standard-user guidance (P1)

- As a standard user, admin-gated sensors stay silent (SMART / disk
  wear, CPU temp, System / Security / Drivers / Updates / Startup /
  Crash history). Show a plain, prominent notice when the scan detects
  admin-gated gaps: "Run as administrator for full results". Do not
  leave the user guessing why half the app is blank.

### F4 — Display copy (P2)

- Display card reads "Not reported by hardware 1920 x 1080 60 Hz"
  although resolution and refresh ARE reported. Show the real values
  first; mark only the missing field (panel model) as not reported.

### F5 — netsh Wi-Fi parsing (P2)

- On a connected adapter (link speed 72.2 Mbps reported), SSID,
  signal, band, channel, radio type, negotiated standard, receive /
  transmit rates are all "Not reported by hardware" (source: netsh
  wlan show interfaces). Fix the parsing (interface-name match, locale,
  command failure as standard user). Add a test with a real netsh
  sample output.

### F6 — CPU temperature + History chart (P2)

- LibreHardwareMonitor reports no CPU temp on this Lenovo, so the
  History chart is empty: "89 samples, 89 gaps where the sensor did
  not report." Handle the all-gaps case gracefully with clear
  empty-state text, not a blank chart that looks broken.
- History chart times must use local time, not UTC (chart showed
  08:45-08:48 for a 13:45-13:48 local scan).

### F7 — Driver-age rule everywhere (P2)

- Network flags its 2022 driver as 4 years old. GPU driver
  (2021-11-15) and Ethernet driver (2019-06-06) get no flag. Apply the
  same older-than-2-years rule to every component.

### F8 — New Laptop Check honesty (P2)

- The PDF says "0 of 10 buyer checks passed" but the detail is 1
  Failed (battery cycles 42) and 9 Not applicable. Report the real
  split ("1 failed, 9 not applicable, 0 passed") instead of "0 of 10".
- Fix the BIOS-date check: it says "BIOS date was not available"
  while the Motherboard page shows BIOS date 2025-09-06. The check
  must use the date the Motherboard collector already reads.

### F9 — Raw-value formatting (P2)

- Battery Chemistry shows "5269836" — decode the enum to Li-ion etc.
- RAM Form factor shows "RIMM" — this machine is SODIMM; verify the
  mapping table (likely an off-by-one).
- Storage "Operational status: 2" — display "OK".
- Panel serial "0" — display Not reported.
- BIOS vendor "Not reported" while BIOS version (N24ET81W 1.56) and
  date (2025-09-06) are present — read the vendor or say why it is
  missing.

### F10 — Export UX (P2; exports WORK)

- JSON/PDF/CSV ARE written to Documents\TrueSpec (confirmed by the
  folder screenshot and the PDF itself). The user thought export was
  broken because the save is silent and he expected Downloads.
- After every export, show an unmissable confirmation with the exact
  path plus "Open folder" and "Open file" actions. Consider Downloads
  as the default (or ask on first export). Settings already lets the
  user change the folder — the problem is the silent save, not the
  location itself.
